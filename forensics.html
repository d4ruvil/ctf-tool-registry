    Forensics Tools – Complete CTF-Oriented List¶

    This is a strict Markdown, CTF-focused, practical digital forensics tools list. Designed for use in a web-based registry (MkDocs / Docusaurus / GitHub Pages).

    1. General / First-Look Tools (Always Use)¶

    • file
    • strings
    • xxd
    • hexdump
    • binwalk
    • binwalk -e
    • foremost
    • exiftool

    2. Disk / Filesystem Forensics¶

    • Autopsy
    • The Sleuth Kit (tsk)
    • fls
    • icat
    • mmls
    • fsstat
    • mount
    • losetup
    • testdisk
    • photorec

    3. File Carving / Data Recovery¶

    • foremost
    • scalpel
    • photorec
    • bulk_extractor

    4. Memory Forensics¶

    • Volatility
    • Volatility3
    • Rekall
    • LiME
    • avml

    5. Network / PCAP Forensics¶

    • Wireshark
    • tshark
    • tcpdump
    • NetworkMiner
    • Zeek (Bro)

    6. Log & Timeline Analysis¶

    • log2timeline (plaso)
    • Timesketch
    • journalctl
    • last
    • lastlog

    7. Image / Metadata Forensics¶

    • exiftool
    • jpeginfo
    • jhead
    • pngcheck
    • tiffinfo

    8. Document Forensics¶

    • pdfinfo
    • pdf-parser
    • oletools
    • olevba
    • officemalscanner

    9. Malware / Suspicious File Analysis¶

    • strings
    • pefile
    • Detect It Easy (DIE)
    • Capa
    • YARA

    10. Mobile Forensics (CTF-Relevant)¶

    • adb
    • sqlite3
    • androguard

    11. Steg + Forensics Hybrid Tools¶

    • binwalk
    • zsteg
    • stegsolve
    • steghide

    12. Online / Helper Tools¶

    • VirusTotal
    • CyberChef
    • AnyRun

    13. Notes¶

    • Forensics CTFs often combine steg + crypto + filesystem
    • Timestamps and metadata are common hiding places
    • Always check deleted files and slack space

    Rule: If a tool appears in a real CTF writeup and is missing — add it.
